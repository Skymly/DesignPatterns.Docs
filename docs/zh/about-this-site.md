# 关于本站

**DesignPatterns.Docs** 是 [DesignPatterns](https://github.com/Skymly/DesignPatterns) 的用户文档站。

| 项 | 位置 |
|----|------|
| 源码与 CI | [github.com/Skymly/DesignPatterns](https://github.com/Skymly/DesignPatterns) |
| 示例 | [github.com/Skymly/DesignPatterns.Samples](https://github.com/Skymly/DesignPatterns.Samples) |
| 本站 | [github.com/Skymly/DesignPatterns.Docs](https://github.com/Skymly/DesignPatterns.Docs) |

正文为 **English**（`docs/`）与 **简体中文**（`docs/zh/`）。生成器贡献说明仍在主仓 `AGENTS.md` 与 `docs/DEVELOPMENT.md`。

基于 [VitePress](https://vitepress.dev/)，部署于 GitHub Pages，base 路径 `/DesignPatterns.Docs/`。
