# About this site

**DesignPatterns.Docs** is the user-facing manual for the [DesignPatterns](https://github.com/Skymly/DesignPatterns) project.

| Item | Location |
|------|----------|
| Source code & CI | [github.com/Skymly/DesignPatterns](https://github.com/Skymly/DesignPatterns) |
| Samples | [github.com/Skymly/DesignPatterns.Samples](https://github.com/Skymly/DesignPatterns.Samples) |
| This site | [github.com/Skymly/DesignPatterns.Docs](https://github.com/Skymly/DesignPatterns.Docs) |

Content is written in **English** (`docs/`) and **简体中文** (`docs/zh/`). Contributor notes for the generator repo remain in the main repository `AGENTS.md` and `docs/DEVELOPMENT.md`.

Built with [VitePress](https://vitepress.dev/). Deployed to GitHub Pages at `/DesignPatterns.Docs/` base path.
